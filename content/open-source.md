# Open Source, Products &amp; Ventures

**Craft developed in private. Useful tools documented and released open.**

loopwright operates across several interconnected creative and engineering workshops. When we build infrastructure for ourselves or solve complex editorial problems, we release reusable patterns as open-source software and package polished systems as standalone digital products.

---

### Open-Source Tools

We believe in durable, zero-dependency tools that put creators in control of their own computing:

- **Clean Static Publishing:** Micro-utilities for static document pipelines, markdown ledger validation, and privacy-first site deployment.
- **Privacy Defaults:** Boilerplates that eliminate third-party telemetry, font surveillance, and cookie rot.
- **Code Repositories:** Explore our public code on [GitHub](https://github.com/loopwright). *(Repository naming transition staged for review).*

### Digital Products

For creators who prefer to build independently without hiring a studio:

- **[Folio &mdash; The Editorial Author Template](/blog/services/)**
  A distinguished, zero-dependency HTML5/CSS website template for novelists, poets, and essayists. Includes dedicated bibliography, excerpt anchors, agency representation notices, and light/dark mode support. Designed for free hosting on Cloudflare Pages or GitHub Pages. *(Recommended: &euro;49 &middot; Staged for release)*.
